V228 adds /api/public-gold-read, a hardcoded read-only fixed upstream endpoint without user-provided URL/query. It obtains the existing public-gold-live-xauusd aggregated reference. If it cannot verify a strictly fresh actual broker tick or attributable indicative spot, it separately attempts existing public-gold-live-api as a research-only fallback. The handler never creates a broker tick, changes its timestamp, submits an order or promotes a stale quote. Broker live is based on the existing 5-second provenance and bid/mid/ask guard. Research indicative XAUUSD requires source quote_type spot_indicative and source timestamp within 15 minutes and may never satisfy the launch Gold gate. If no acceptable observation exists, HTTP 503 and WAIT / 0R. Concurrency guarded per instance by V223.

Gold Live, Market Live, Visual Lab, production /status and both browser checkout verification paths now share the fixed no-query read endpoint. Checkout remains hard-locked until reviewed server-side acceptance is deployed; genuine broker-live access still requires an enrolled read-only MT5 terminal actively sending ticks, not a substitute market snapshot.
